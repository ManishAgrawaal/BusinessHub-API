# BusinessHub API

ASP.NET Core Web API backend for the BusinessHub platform, supporting public inquiries, admin management, client portal, projects, milestones, quotes, messages, documents, authentication, and authorization.

## Tech Stack

- .NET 10 / ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication & Role-Based Authorization
- REST APIs
- Swagger / OpenAPI
- LINQ
- Dependency Injection
- EF Core Migrations
- Git & GitHub

## Key Features

- Admin & Client authentication
- Role-based authorization
- Client management
- Project & milestone management
- Project inquiries
- Quotes & proposals
- Client-admin messaging
- Document management
- Secure REST API architecture

## Deployment

- Hosting: MonsterASP
- Application: ASP.NET Core Web API
- Database: SQL Server
- Source Control: GitHub
- API Deployment: MonsterASP
- Production Configuration: Environment-based configuration

## Architecture

React Frontend → ASP.NET Core Web API → SQL Server
